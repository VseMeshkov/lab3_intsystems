# Лабораторная работа № 3 — вариант 12

Дифференцируемая оптимизация порядка и выбор ветви модели Yeoh.

- `lab3_variant12.ipynb` — выполненный ноутбук с расчётами, графиками и источниками.
- `lab2_core.py`, `lab3_core.py`, `lab3_plots.py` — модули для запуска ноутбука.
- `presentation.pptx`, `presentation.pdf` — презентация в редактируемом формате и PDF.
- `results/` — таблицы результатов и журнал выборки графов.
- `figures/` — изображения графиков.
- `verify_results.py` — проверка градиента, разделения данных и сохранённых результатов.
- `provenance.json` — контрольные суммы исходных материалов и версии библиотек.

## Запуск

Python 3.10 или новее. Команды выполняются из этой папки:

```bash
python -m pip install -r requirements.txt
jupyter notebook lab3_variant12.ipynb
```

В Jupyter выполните Run All. Данные встроены в код; интернет для расчётов не нужен.
Проверка результатов: `python verify_results.py`.

и 2 test точки; этот объём ограничивает обобщаемость выводов.
